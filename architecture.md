# Architecture Memory

Updated 2026-10-20. ArcTradeProof AI is a React/Vite frontend and Express API for advisory document analysis and buyer-authorized USDC escrow. Vercel with Node 24.x is the selected hosting path; Bun remains local development/test/install tooling.

- `src/main.tsx`: React/wagmi/ConnectKit entry. `src/config.ts`: Arc Testnet plus Ethereum mainnet for ENS; no Arc Mainnet escrow deployment. Studio imports in both files require DEV and VITE_STUDIO_DEBUG=true; Vite excludes them in production.
- `server/index.ts`: createApp factory; `/api/health`, `/api/extract`, `/api/compare`, `/api/report`. Standalone production still serves dist/. `api/index.ts` exports createApp with serveStatic=false and no listener. Vercel serves Vite's dist/ via its static layer; vercel.json explicitly routes bare /api and /api/* to the Function and excludes them from the SPA fallback. API catch-all remains JSON 404.
- `server/schemas.ts`: bounded upload/document/model output schemas. `server/lib/pdfExtract.ts` uses pdf-parse v2 with ten-page and text bounds. `server/lib/compare.ts` uses exact BigInt monetary comparison and rejects malformed amounts.
- `server/ai.ts`: server-only OpenAI provider. AI_MAX_CALLS (default zero, maximum 300) and absolute AI_BUDGET_FILE control a persisted lifetime allowance. Exactly one process/instance on persistent storage; attempts reserved before provider calls, no retries, concurrency two, output cap 2500 tokens, 30-second abort plus disconnect cancellation. No backend transaction execution.
- Production origins: PUBLIC_ORIGIN overrides platform fallback; VERCEL=1 selects https://VERCEL_URL, otherwise the historical RENDER_EXTERNAL_URL fallback. Optional ALLOWED_ORIGIN adds one exact origin. Only exact HTTPS origins are accepted; no request-header-derived origin. Missing/blank configuration denies Origin-bearing requests. Set PUBLIC_ORIGIN for a stable production/custom Vercel domain and use the unique generated URL for previews. TRUST_PROXY_HOPS stays zero until host verification. POST rate limit is 20/15 minutes per instance/client key, not a global serverless quota.
- `src/store/dealReviewStore.tsx`: in-memory review evidence/deal binding, approval reset on rebinding. `src/lib/reviewHash.ts` hashes canonical evidence JSON. `src/components/ApproveAndRelease.tsx` passes dynamic reviewHash to wallet simulation, checks calldata equality, and gates submission on explicit approval and matching deal/buyer.
- Contract/tests unchanged by Stage 5.2. Buyer-only release is enforced by `contracts/ArcTradeProofEscrow.sol`. Deal #1 is RELEASED (4), per owner-confirmed testnet TX6 recorded in README. Do not repeat it.
- Commands: bun run test:all; lint:app/typecheck:app (also default lint/typecheck) cover src/server/api/tests/vite.config.ts with unchanged strict settings; bun run build/start (start is standalone only); forge test for contracts. scripts/tsconfig.json provides separate strict Studio tooling scope via lint:studio/typecheck:studio. package.json engines.node=24.x selects Vercel Node; no bunVersion runtime override.
- Studio tooling caveat: scripts/compass-deploy.ts imports unavailable @circlefin/compass-chains and dynamically loads further Compass modules, with Studio-specific workspace/RPC assumptions. Separate Studio checks remain failing/unverified; deployment sources are preserved. See docs/stage5.3-report.md.
- Standalone budget state is the integer in AI_BUDGET_FILE; local restart persistence was tested, not crash/storage-loss durability. VERCEL=1 rejects file budgets before reading or reserving anything, even with a key and positive allowance. Paid AI remains zero/off. Future Vercel inference requires an authenticated shared transactional budget/concurrency design; no store is provisioned. See docs/stage5.4b-vercel-report.md.
- Render is no longer selected. docs/stage5.4a-report.md remains unchanged historical evidence. Vercel uses native Node Functions with NODEJS_HELPERS=0 (Express parses bodies), maxDuration=60, and Vite static output; all actual cloud build, TLS, proxy and browser verification is pending. Local official builder transpilation and Node HTTP tests do not prove a deployment.
- Standalone startup limits: listen reads PORT and uses the runtime's wildcard interface default; historical local Bun verification reports :: and accepts IPv4. Invalid origin/proxy/port configurations fail startup. Vercel's api/ entry does not listen. Health is API liveness, not a static asset, wallet, RPC or inference check; public HTTPS requires later deployment verification.
- Frontend remains a fixed testnet demo: src/escrow.ts holds the v2 contract, demo participants and Deal #1; several transaction components retain fixed participant/evidence guards. A public page is not a generalized new-deal workflow. No transaction is needed for deployment verification.
- Prototype caveats: real AI inference and mainnet deployment unverified; anonymous allowance exhaustion possible; PDF parser not resource-isolated; AI cannot verify physical delivery. No credentials or secret values belong in this file.
